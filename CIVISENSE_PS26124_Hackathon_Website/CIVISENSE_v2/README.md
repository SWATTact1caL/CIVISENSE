# CIVISENSE v2 — Problem Statement 26124

Frontend prototype for the AI-Powered Mobile Urban Intelligence Platform Using Public Transport Fleet.

Run with `python -m http.server 8000` and open `http://localhost:8000`.

Includes Urban Command Centre, GIS-style event map, road-defect AI events, traffic density/bottlenecks, infrastructure deficiency queue, ANPR incident evidence, fleet/driver dashboard, onboard camera health, weather, route progress, SOS workflow and Google Maps navigation.

Demo values are simulated. Connect real GPS, edge-AI inference, weather, ANPR and backend services for production.
